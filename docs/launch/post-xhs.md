## 正文

做实证研究的朋友看过来 👀

我做了一个开源项目「免费助研团 Free-Research-Crew」：
一群 AI 助研在 Claude Code 里协作，从研究问题一路做到一篇编译好的论文，数据分析、实验、图表、写作、复现都包了。

但重点不是“会写”，是“不骗你”👇

✅ 每个结果数字都从运行日志自动生成，不能手敲
✅ 研究设计批准前，不许看结果
✅ 投稿前必须在全新环境重跑一遍，结果一致才算
✅ 有一个审稿人 AI，从不写字，只负责挑刺，每次先写“拒稿的最强理由”
✅ 四道关卡（问题、设计、结果、投稿），每一道都要你亲口批准

📄 已经写完 6 篇样例论文，全部公开：
· 401(k) 双重机器学习复现
· Card–Krueger 最低工资复现
· LaLonde 培训项目评估
· 一个真实效应为零的陷阱数据（它没有“发现”不存在的效应）
· 两篇机器学习：标签噪声、概率校准

🔍 审稿人一共审了 68 轮，提出 12 个致命问题、210 个重大问题，比如：
· 发现移植的 lasso 少了一步，补上后 Python 和 R 的差距从 87 美元降到 0.36 美元
· 发现一个“显著”结果其实在随机种子的噪声之内

💰 每篇按 API 标价折算约 58–103 美元的模型用量，用 Claude 订阅则计入额度
