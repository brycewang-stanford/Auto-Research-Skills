## 正文

很多“AI 科学家”项目能从一个想法一路写到 PDF。问题在于：同一个系统既做实验、又挑规格、又把数字敲进论文、又给自己打分。每一步都可能悄悄出错，而没人看得见。

**免费助研团（Free-Research-Crew）** 换了个思路：把“判断”拆开。

- **发生了什么**——交给一个确定性的小工具：实验跑完没有？论文里的数字是不是等于日志里的那个？
- **做得好不好**——交给一个专门挑刺的「审稿人」智能体，它从不参与写作，只读文件、不听作者解释。
- **要不要继续**——交给你。研究问题、研究设计、结果、投稿，四道关卡，每一道都要你点头。

团队里有九个角色：PI、文献、设计、数据、计量（社科）/ 实验（CS）、图表、写作、复现，外加审稿人。它们跑在你已经在用的 Claude Code 里，不需要服务器，不需要额外的 API 账单——这就是“免费”。

### 审稿人到底拦下了什么

我们用三个样例任务做了完整测试（全部过程公开在 `gallery/`）：

1. **401(k) 双重机器学习复现**（社科）。第一轮，审稿人指出复现的容差是按抽样误差定的，太宽——一个随手做的复现也能“通过”。改完第二轮，它又指出容差太严——一个忠实的复现也大概率“失败”。第三轮推出了正确的公式。之后它读代码时发现：我们移植的 lasso 少了 R 包 hdm 里一个把极小系数清零的步骤；把这一步补上，Python 和 R 的差距从 87 美元降到 0.36 美元。
2. **一个真实效应为零的就业培训评估**（社科）。这是专门设计来诱惑“p 值操纵”的数据：很多结果变量、20 个无关的问卷题。审稿人在设计阶段直接**否决**了一个看似严谨的安慰剂检验——因为参加者在入学前有收入下滑，这个检验无论假设对错都会“失败”，只会在看到结果后制造岔路。最终：主效应 −9.8 美元，95% 区间 [−358, 338]；有一个次要结果在校正前 p = 0.044，按事先写好的规则，**不报告为发现**。
3. **标签噪声对三种表格分类器的影响**（CS）。审稿人发现小数据集上每个种子都在重切同一批样本，原计划的置信区间只有诚实区间的四成宽。最终两个假设都是“无法判定”——这就是这个设计在这个算力下能给出的诚实答案。

它也拦下了我们自己人：一个文献 Agent 手敲了一条时间戳在未来的日志，被审稿人发现后，我们给工具加了“日志只能由工具写入”的硬约束。

### 怎么用

```bash
claude plugin marketplace add brycewang-stanford/Free-Research-Crew
claude plugin install crew@free-research-crew
# 在 Claude Code 里：
/crew:start ss-dml-401k
```

### 说清楚的局限

- 关卡由人批准，是智能体遵守的规则，不是技术锁。
- 审稿人默认和作者同一家模型（只是全新上下文）；可选用另一家模型做交叉审稿。
- 样例论文是演示，不投期刊。
