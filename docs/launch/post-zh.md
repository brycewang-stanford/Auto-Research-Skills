## 正文

很多“AI 科学家”项目能从一个想法一路写到 PDF。问题在于：同一个系统既做实验、又挑设定、又把数字敲进论文、又给自己打分。每一步都可能悄悄出错，而没人看得见。

**免费助研团（Free-Research-Crew）** 换了个思路：把“判断”拆开。

- **发生了什么**，交给一个确定性的小工具：研究设计批准之前不许跑分析；论文里的每个结果数字都是从运行日志自动生成的 LaTeX 宏；跑完之后改了代码，这次运行就作废；每条引用都要有核对记录；投稿前必须在全新环境里把所有运行重跑一遍，结果一致才算数。
- **做得好不好**，交给一个专门挑刺的「审稿人」智能体。它从不参与写作，只读文件、不听作者解释，每份审稿意见都以“否决论证”开头：用一段话写出拒稿的最强理由。
- **要不要继续**，交给你。研究问题、研究设计、结果、投稿，四道关卡，每一道都要你亲口批准。一个钩子会拦下任何不是你批准的“通过”。

团队有九个角色加一个 PI：文献、设计、数据、计量（社科）/ 实验（CS）、图表、写作、复现，外加审稿人。它们跑在你已经在用的 Claude Code 里，不需要服务器，也不需要另开账号。

### 六篇论文，全部公开

我们用六个样例任务做了完整测试：四个社科（三篇经典复现，一个“真实效应为零”的陷阱），两个机器学习。每篇都通过了四道关卡和干净重跑，所有工作区、审稿意见和关卡决定都在 `gallery/` 里。

| 论文 | 结果 |
| --- | --- |
| 401(k) 双重机器学习复现 | 已发表表格的 10 个格子全部落在事先定好的容差内 |
| 真实效应为零的培训评估 | −9.8 美元，95% 区间 [−358, 338]，没有“发现”不存在的效应 |
| Card–Krueger 最低工资复现 | 三个目标复现两个；第三个在容差内，但没达到发表精度，原因未查明，照实写 |
| LaLonde 观察性估计 | 1,573 美元 [9.6, 3,136]，但在随机种子的噪声之内；安慰剂检验失败，所以只能叫“两组差异”，不能叫“项目效应” |
| 标签噪声（ML） | 两个假设都无法判定 |
| 概率校准（ML） | 第一个假设被推翻，两个重校准假设一个无法判定、一个无差异 |

你会发现，很多结论是“无法判定”或“不成立”。这不是失败，是这套流程在这些数据和算力下能给出的诚实答案。

六篇加起来，审稿人一共审了 68 轮，提出 12 个致命问题、210 个重大问题、373 个小问题。没有一道关卡是在致命问题未解决时放行的。

### 审稿人到底拦下了什么

1. **401(k) 复现**：第一轮，审稿人指出复现容差是按抽样误差定的，太宽，随手做的复现也能“通过”；改完又指出太严，忠实的复现也会“失败”；第三轮才推出正确的公式。读代码时它还发现，我们移植的 lasso 少了 R 包 hdm 里把极小系数清零的一步。补上之后，Python 和 R 的差距从 87 美元降到 0.36 美元。
2. **零效应陷阱**：数据专门设计来诱惑 p 值操纵，结果变量很多，还有 20 个无关的问卷题。审稿人在设计阶段直接否决了一个看似严谨的安慰剂检验：参加者入学前有收入下滑，这个检验无论假设对错都会“失败”。最终有一个次要结果校正前 p = 0.044，按事先写好的规则，不报告为发现。
3. **LaLonde**：主估计的 95% 区间以 9.6 美元之差排除零。审稿人指出，5 次交叉拟合重复里有 3 次单独看并不排除零；它还发现，有一条“对种族稳健”的敏感性结论其实是算法把一个量截到零造成的假象。论文现在把这两点都写进了正文和摘要。
4. **概率校准**：相关工作里有一句话，把一个数字算在已发表论文头上，其实这个数字是我们的助研自己从作者公开的数据里数出来的，用的还是一个没留记录的脚本。审稿人揪出来以后，这句话删了。
5. **标签噪声**：小数据集上每个种子都在重切同一批样本，原计划的置信区间只有诚实区间的四成宽。

它也拦下了我们自己：一个文献助研手敲了一条时间戳在未来的日志。之后我们加了专门写日志的命令，校验也会拒绝未来时间。PI（也就是编排其他角色的那个会话）几次跳过了第二轮代码审稿，也都由审稿人指出，写进了论文的披露。

### 花了多少

每篇从开题到投稿关卡用了 18–25 小时，其中不少是在等我审批。模型用量按 Claude API 标价折算约 58–103 美元一篇；用 Claude 订阅的话，计入订阅额度，不另付费。所有数字都是从对话记录里量出来的，见 `gallery/usage.json`。

### 怎么用

```bash
claude plugin marketplace add brycewang-stanford/Free-Research-Crew
claude plugin install crew@free-research-crew
# 在 Claude Code 里：
/crew:start
```

### 说清楚的局限

- 关卡批准由一个 Claude Code 钩子把守：只有你最新的一条回复批准了这道关卡，“通过”命令才会生效。但钩子之外，有心的智能体或手工改文件仍然绕得过去。
- 工具只能检查数字是否来自运行日志，不能检查文献是否真说了那句话。那是审稿人的活，审稿人也会错。
- 审稿人默认和作者是同一家模型（只是全新上下文）；可以选用另一家模型做交叉审稿。
- 样例任务都按笔记本电脑的算力设计；论文是演示，不投期刊。
