About 80% of the usage is the role subagents (18–31 per paper); the rest is the PI
session, whose requests are split among the papers it was running at the time. The papers
ran in parallel from one PI session, so elapsed times overlap. The figures are re-measured
whenever a paper is added, so earlier papers' shares of the PI session can shift slightly.
`ss-card-proximity` cost the most: protocol 0.2 reviews code before it runs, which added
four code rounds, and the Reviewer ran 15 rounds in all.

### The low-cost trial

`ss-rd-senate` ran every role subagent, the Reviewer included, on Claude Haiku 5.5 (the
PI session stayed on Claude Opus 5.5). The 23 subagent runs cost about $2 at API list
prices, against roughly $40–115 for the subagents of each other paper; the PI session
(about $16) became most of the bill. The protocol held: the Haiku Reviewer blocked the
first question, ran 15 rounds, read the rdrobust source to check software behaviour,
caught a reversed sign, a proportion-versus-percentage-point scale error and a false
statement in the run notes, and twice overruled the PI. It also needed more rounds than
the Opus-reviewed papers, and the Haiku roles made more slips for it to catch. The clean
rerun exposed two bugs in `crew.py` itself (fixed, with tests). Running the PI on a
smaller model too would bring a paper to a few dollars; see
[`crew/README.md`](../crew/README.md#choosing-models).

### Answer key: ss-card-proximity

The scorer marks this paper **fail**: `iv-return` (0.1324) is inside the key's bounds,
`first-stage` (0.3639) is not. The seed asked for "the first-stage coefficient on the
instrument" without naming a column. The crew's approved design mapped it to Card's basic
specification (Table 3 Panel B column 2, printed 0.365), the same specification as
`iv-return`; the key checks the experience-exogenous column without family background
(Panel A column 1, printed 0.320). The paper reports that column too, and its replicate,
0.3199, lies inside the key's bounds. The result stays a fail, because the claim the seed
named does not match the key. The seed now names the column, so the ambiguity cannot
recur.

## Reading a workspace

Start with `plan.json` for the question, the design and the gate decisions, then
`reviews/` for what the Reviewer attacked and how each finding was resolved, then
`paper/main.pdf`. To check a number, find its macro in `claims.jsonl` and follow it to
the run in `runs/`. Run `python3 crew/scripts/crew.py validate gallery/<paper>` to check
the whole workspace, or `crew.py rerun` to reproduce it. The file formats are in
[`crew/PROTOCOL.md`](../crew/PROTOCOL.md).

Raw data files are not committed; each workspace's `data/manifest.json` says where to get
them and their hash.

## What the Reviewer caught so far

- **cs-label-noise:** a main hypothesis that averaged over datasets not yet named; small-dataset intervals ~40% as wide as honest ones; an ablation mislabelled as a mechanism. It also ran a pilot before the design gate itself, which is disclosed and led to a new rule.
- **ss-dml-401k:** a replication tolerance first too loose, then too strict; a "not testable" rule that discarded failures; a Python lasso missing hdm's zero-threshold step (R–Python gap $87 → $0.36 after the fix).
- **ss-null-effect:** a placebo test that a pre-program earnings dip would make "fail" either way (the design was blocked); a hand-typed log entry stamped in the future; an alternative estimate explained away in the notes.
- **ss-card-proximity:** the seed and Card's own codebook cite the wrong working paper (WP 4832; the proximity paper is WP 4483); a missed prior reanalysis (Cinelli and Hazlett 2025) that had already published Anderson–Rubin sets on these data; robustness checks planned on a specification that treats experience (age − schooling − 6) as exogenous although schooling is not, which Card himself flagged; an interval for the IV−OLS gap that was not valid; a tool bug that counted a finding carried across review rounds once per round (fixed); a timeline for reading Card's SAS output that the log contradicted; and a unit slip that called 0.011 "log points".

## Disclosure

These papers are demonstrations of the crew. They are not submitted to journals or
conferences. The `ss-null-effect` seed (its synthetic data and hidden answer key) was
written by the same session that acted as PI; the analysing agents never saw the key. Each was directed by a human who approved its four gates; the AI-use
statement in each paper says which models did what.
