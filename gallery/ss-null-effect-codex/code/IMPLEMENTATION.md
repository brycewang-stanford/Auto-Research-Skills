## Numerical conventions and failure handling

Read only authorized prefix fields; excluded outcome values are never converted, summarized or searched. Source bytes are hashed opaquely. Data corruption/schema/missingness failures stop the command rather than repair the sample. The reader relies on the documented no-quoted-comma layout of the hash-pinned source prefix, matching data-prep. Support/precision/placebo do not convert re78.

AIPW uses full-sample unpenalized logistic MLE (`newton`, maxiter 2000, tol 1e-8), OLS among controls, and an unnormalized sum divided by treated count. Primary odds are neither clipped nor trimmed. Capped odds are changed only in the estimating equation, after unchanged nuisance fits. All three bootstrap runs initialize the same PCG64 seed and independently make 499 individual-row resamples, fitting both nuisances in each. Original full-sample region columns remain fixed in bootstrap samples; a missing category can cause the prespecified rank failure. Any perfect-separation warning is treated as failed propensity fitting. Invalid original fit is retained as `fit_ok=0`, with reason and resamples not attempted; failed resamples are counted by exception type. Fewer than 490 successful resamples or invalid SE leaves `fit_ok=0` without replacing the estimate. Main has no inferential p-values on such failure.

Statistical failures are successful file-producing commands reporting failure status; data-validation or unexpected software errors remain failed commands. A successful command is not a successful causal estimate. Decision-report requires all seven predecessor metric files, preserves five p-values even when failed tests become p=1, reports fit flags and suppresses affirmative interpretations on primary/support failure. Point estimates whose uncertainty failed are available in their original run but are not used for inferential decisions. Metrics are flat finite JSON with absent/undefined quantities omitted and explicit availability flags; there are no NaN stand-ins. Bias scenarios are signed shifts `tau_hat-b`; bias-to-boundary metrics give signed b for each point/95% endpoint to equal zero or either benchmark boundary, not identified bounds.

OLS uses normal HC3 individual robust inference and is a constant additive regression coefficient. Its 90% marginal interval is mechanically generated by the shared inference helper but is not an additional equivalence test and is not intended for reporting. Only main has TOST. Four 99% intervals and the primary 98% interval appear in decision-report; marginal 95% limits remain clearly named. ## Inferential derivation and limits (L1)

Let theta collect logistic coefficients, control OLS coefficients, the ATT and treated proportion. Logistic score moments `X(D-e)`, control regression moments `(1-D)X(Y-X beta)`, the ATT moment `D(Y-X beta-tau) -(1-D)e/(1-e)(Y-X beta)`, and the treated-proportion moment form a finite-dimensional smooth estimating system. The implemented ATT is the sample solution for tau. Under IID observations, unique interior nuisance solutions, finite sufficient moments, nonsingular Jacobian and adequate overlap, a Taylor expansion of these empirical moments gives an asymptotically linear estimator with Gaussian limit. Refitting every component in a row bootstrap estimates this joint first-order distribution; it includes nuisance estimation rather than treating fitted scores as known. This is an asymptotic regularity argument, not a finite-sample or uniform guarantee and not an application of a cross-fitting theorem.

For the estimand, if m0 is correct then conditional control residual means vanish and participants' residual mean gives ATT. If e is correct, the control-odds identity changes the expected weighted residual into the participants' expected untreated residual for any fixed working m0, yielding the same ATT moment. Either argument additionally requires the causal mean-exchangeability, consistency/no-interference and support assumptions. If both nuisances are misspecified, the equation generally targets a conditional association, not the ATT. Capping breaks the exact weighting identity. Weak overlap, separation, heavy tails, dependence, nonregular fits or near singularity can defeat bootstrap/Wald validity even when software finishes. No cluster identifier is supplied; region is a covariate, not an assignment cluster. Full-cohort support flags block affirmative interpretation; they do not establish hidden-selection absence when absent. L1's request for estimator-specific grounding is for independent review: this derivation does not self-resolve the finding or add an unverified reference.
