# 🧰 Starter Kits — collision-free skills per research stage

> Generated by [`tools/build_starter_kits.py`](../tools/build_starter_kits.py). Do not edit by hand; run `make starter-kits`.

Out of **6,087** catalogued `SKILL.md` files, these **60** skills from **20** collections form one kit per research stage. Every skill name is unique across all kits, so you can install one kit, several, or all of them into a single agent profile without the name collisions listed in [`collisions.json`](collisions.json).

**How picks are made.** Stage keywords are matched against each skill's name (weighted ×3) and description. Matches are ranked by on-disk depth (bundled references, scripts, examples, evals, tests — see [`MATURITY.md`](MATURITY.md)), a clear trigger description, and declared license metadata. Hard gates:
canonical copies only, no templates, no collection-root skills, at most one skill per collection per stage, and no skill whose own directory has a high/critical safety finding in a skill/script file (see [`SAFETY.md`](SAFETY.md)).

**Install a kit** (copies each skill directory; refuses to overwrite):

```bash
./setup.sh   # or: git submodule update --init --depth 1
python3 tools/build_starter_kits.py --install literature --dest ~/.claude/skills
python3 tools/build_starter_kits.py --install all --dest ~/.codex/skills --dry-run
```

> These are heuristic, reviewer-assist picks — a strong starting point, not an endorsement. Read each `SKILL.md` before relying on it; the safety gate catches known-dangerous patterns, not every risk.
